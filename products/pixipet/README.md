# Pixipet

macOS 화면에 항상 떠 있는 픽셀 아트 동물 캐릭터 앱입니다. 캐릭터는 화면 아래를 걷고, 마우스를 바라보고, 타이머 종료나 Claude Code 작업 완료 같은 이벤트에 반응합니다. 여러 동물을 지원할 예정이며, 첫 동물은 여우입니다.

| 경로 | 내용 |
|---|---|
| `app/` | macOS 앱 소스 코드 (아직 없음) |
| `characters/` | 동물 스프라이트, 생성 도구, 뷰어, 스타일 가이드, 작업 기록 |
| `design-system/`, `images/`, `svg/`, `poc/` | 저장소 공통 구조. 앱 UI(설정 화면, 아이콘 등)를 만들 때 씁니다 |

캐릭터를 만들거나 고치기 전에 `characters/docs/fox-design-log.md`를 먼저 읽습니다. 원하는 느낌과 지금까지의 수정 이력이 정리되어 있습니다.

# 북극여우 작업 기록

2026-09-29에 여우를 바탕으로 북극여우를 만든 과정을 정리한 문서입니다. 여우의 프레임, 동작, 타이밍은 그대로 쓰고, 털색과 머리 모양만 바꿨습니다.

- 요청 원문은 [`arctic-fox-prompts.md`](arctic-fox-prompts.md)에 있습니다. 이 문서의 `#n`은 그 문서의 번호입니다.
- 여우에서 정한 원칙은 그대로 따릅니다. 이 문서는 북극여우에서 **새로 알게 된 것**을 중심으로 적었습니다.

## 1. 만드는 방법

`tools/assemble_arctic_fox.py`가 `sprites/arctic-fox.json`을 씁니다. 여우 생성기(`draft_fox.py`, `fox_poses.py`)의 소스에서 머리 그림 몇 군데를 바꿔 실행하고, 동작 정의는 `assemble_fox.py`의 것을 씁니다. 그래서 여우를 고치면 북극여우도 다시 생성하기만 하면 됩니다. 바꿀 문구가 여우 소스에서 정확히 한 번씩 나오지 않으면 파일을 쓰지 않고 멈춥니다.

```sh
python3 tools/assemble_arctic_fox.py && node tools/build.mjs
python3 tools/render_video.py arctic-fox     # dist/arctic-fox-all-animations.mp4, 여우와 같은 해 질 녘 무대
```

## 2. 털색 (#1, #2)

겨울털, 여름털(회갈색), 블루 모프(짙은 청회색) 세 가지를 같은 프레임에 칠해서 비교했고, 겨울털로 정했습니다.

- **흰 털과 흰 테두리:** 털을 흰색으로 칠하면 흰 1px 테두리와 합쳐져서 윤곽이 사라집니다. 그래서 털은 테두리보다 한 단계 어두운 푸른 회색(`#d9dfe6` 기본)으로 칠했습니다.
- **다리와 귀:** 붉은여우의 검은 다리와 검은 귀 뒷면은 없앴습니다. 다리, 발, 가슴, 꼬리 끝까지 모두 흰 털이고, 눈과 코만 검은색입니다. 먼 다리는 여전히 가까운 다리보다 한 단계 어둡습니다.
- **가슴:** 처음에는 붉은여우처럼 크림색 가슴을 두었는데, 흰 몸에서는 얼룩처럼 보여서 몸과 같은 차가운 흰색으로 바꿨습니다.
- **입 안:** 붉은여우는 하품할 때 입 안을 검은 다리 색(`k`)으로 칠했습니다. 북극여우는 다리가 희어서 입 안이 희게 보였기 때문에, 입 안 전용 색 `m`을 새로 두었습니다.

## 3. 머리 모양 (#2)

북극여우는 추위에 맞게 귀가 작고 둥글며 주둥이가 짧습니다. 다리가 짧은 특징은 반영하지 않았습니다(#2).

- **귀:** 뾰족한 끝 한 칸을 없애서 두 칸 너비로 둥글게 끝납니다. 옆모습, 3/4, 정면, 웅크려 잘 때의 귀를 모두 바꿨습니다. 귀를 쫑긋 세우는 동작(`listen`)에서는 둥근 귀가 한 칸 더 올라가고, 귀를 뒤로 돌릴 때는 앞쪽 한 칸이 빠집니다.
- **주둥이:** 한 칸 짧아서 눈에서 코까지 세 칸입니다.
- **따로 옮긴 곳:** 코, 혀, 입을 따로 찍는 동작은 주둥이에 맞춰 한 칸씩 뒤로 옮겼습니다. 대상은 핥기(혀), 하품(입), RotSprite로 돌린 머리(손으로 찍는 코)입니다. 고개를 크게 돌린 프레임 4개(`pounce_air_6`, `pounce_air_8`, `idle_0_down`, `idle_1_down`)에서는 코 앞에 털 한 칸이 남아서, 코 바로 앞의 외톨이 털 칸을 지우는 후처리를 넣었습니다.
- **그대로 둔 것:** 덮치기에서 흙이 튀는 조각 하나는 전에는 긴 귀에 가려져 있었는데, 이제 머리 위로 보입니다. 흙 조각이라 그대로 두었습니다. 땅 파기와 덮치기의 흙더미도 붉은여우와 같은 갈색입니다.

## 4. 돌아서기 3/4 얼굴 (#3~#5)

- **처음 문제 (#3):** 3/4 얼굴의 눈 두 개와 코가 점 세 개처럼 보여서 무엇이 코인지 알 수 없었습니다. 붉은여우는 주황색 주둥이가 크림색 뺨보다 2칸 앞으로 튀어나와 있어서 그 끝의 점이 코로 읽혔습니다. 북극여우는 주둥이와 뺨이 모두 흰색이라 주둥이 모양이 보이지 않았고, 주둥이를 줄이면서 코가 가까운 눈 옆으로 붙었습니다.
- **진짜 원인 (#4):** 뺨을 어둡게 칠해 주둥이를 드러낸 후보도 여전히 어색했습니다. 눈은 정면처럼 나란히 있는데 코는 옆모습처럼 두 눈보다 바깥 끝에 있어서, 두 시점이 한 얼굴에 섞여 있었기 때문입니다.
- **조치 (#5):** 두 눈 간격을 5칸에서 4칸으로 좁히고(정면은 6칸), 코를 두 눈 사이 아래, 먼 쪽 눈에 가까운 곳으로 옮겼습니다. 주둥이는 오른쪽으로 1칸만 내밉니다. 같은 구조였던 붉은여우도 같은 방법으로 고쳤습니다(`fox-design-log.md`).

## 5. 다음에 점검할 것

1. 털색을 한 가지 색에 가깝게 바꾸면, 이전 팔레트가 색 대비로 보여 주던 모양(주둥이, 뺨, 가슴)이 사라집니다. 옆, 3/4, 정면 얼굴을 모두 확대해서 확인합니다.
2. 흰 털은 흰 테두리보다 한 단계 어둡게 칠합니다.
3. 한 색을 여러 부위에 같이 쓰면(`k`: 다리와 입 안), 색을 바꿀 때 다른 부위도 함께 바뀝니다. 팔레트를 바꾸기 전에 그 색이 쓰인 곳을 모두 찾습니다.
4. 머리 모양을 바꾸면, 코나 혀처럼 좌표로 따로 찍는 픽셀이 예전 자리에 남지 않는지 확인합니다.
